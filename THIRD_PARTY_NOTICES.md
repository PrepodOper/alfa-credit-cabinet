# THIRD_PARTY_NOTICES

Решение использует только open-source компоненты. Платные API, закрытые данные и корпоративные
лицензии не применяются. Все компании, ИНН, финансовые показатели, документы и новости —
синтетические и сгенерированы для демонстрации.

## Смоделированные интеграции (не реальные сервисы)

| Интеграция | Что моделируется | Реализация |
|---|---|---|
| Бюро кредитных историй (БКИ) | Скор, действующие кредиты, задолженность, просрочки, запросы | `backend/app/services/registry.py`, таблица `credit_profiles` |
| ЕГРЮЛ / ЕГРИП | Статус компании, регистрационные данные, руководитель, учредители | `registry.py`, таблица `registry_infos` |
| ФНС «Прозрачный бизнес» | Налоговая задолженность, нарушения, массовый адрес | `registry.py`, таблица `registry_infos` |
| Единая информационная система МСП | Контекст рынка МСП в новостях (без рантайм-вызовов) | контент `news_items` |
| УКЭП / ЭДО | Подписание пакета документов | событие `documents_signed`, демо-режим |
| Расчётный счёт и зачисление | Номер счёта и факт выдачи | генерация номера в `applications.py` |

Все моки детерминированы и описаны в документации (`docs/03-credit-process.md`,
`docs/06-data-model.md`). При подключении реальных API контракты (`services/registry.py`)
заменяются клиентами без изменения логики конвейера.

## Данные

- Все данные о клиентах, компаниях, сотрудниках, финансах, документах и новостях — синтетические,
  созданы командой для демонстрации (`backend/app/seed.py`).
- Персональные данные реальных лиц не используются.
- Внешние датасеты не применялись.

## Модели ИИ

- LLM и внешние ML-сервисы не используются. Персонализация новостной ленты и скоринг —
  детерминированные правила, что обеспечивает воспроизводимость проверки и объяснимость решений.
- При развитии допускается подключение моделей с открытыми весами (ограничение кейса), например
  для ассистента по заполнению заявки или распознавания документов.
