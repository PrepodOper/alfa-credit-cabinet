# КАК ЗАПУСТИТЬ — пошагово

Приложение состоит из двух частей: **backend** (FastAPI, Python) и **frontend** (React).
Собрать его можно тремя способами — выберите любой.

| Способ | Что нужно | Команда | Когда выбирать |
|---|---|---|---|
| **A. Docker** (рекомендуется) | Docker Desktop / Docker Engine | `docker compose up --build` | Проверка «одной командой», ничего не устанавливать в систему |
| **B. Один процесс** | Python 3.11+ | `./start.sh` (Linux/macOS) или `start.bat` (Windows) | Самый быстрый запуск без Node.js |
| **C. Режим разработки** | Python 3.11+ и Node.js 20+ | два терминала: `uvicorn` + `npm run dev` | Хочется править код и видеть hot-reload |

Во всех случаях после запуска:

- приложение — **http://localhost:8000** (способ B/C) или **http://localhost:8080** (способ A);
- API и Swagger — **http://localhost:8000/docs**;
- проверка живости — **http://localhost:8000/api/health**.

---

## Способ A. Docker Compose (рекомендуется)

### 0. Что установить

- **Docker Desktop** — https://www.docker.com/products/docker-desktop/ (Windows/macOS)
- На Linux: `docker` + плагин `docker compose` (пакет `docker-compose-plugin`)

Проверьте, что Docker работает:

```bash
docker --version
docker compose version
```

### 1. Распаковать архив и зайти в папку

```bash
unzip alfa-credit-cabinet-v1.0.0.zip
cd alfa-credit-cabinet
```

### 2. (Необязательно) создать файл окружения

```bash
cp .env.example .env        # Windows PowerShell: copy .env.example .env
```

Можно пропустить — значения по умолчанию рабочие. В `.env` меняют `JWT_SECRET`, задержки конвейера и т.п.

### 3. Запустить

```bash
docker compose up --build
```

Первый запуск занимает 2–4 минуты: скачиваются базовые образы (python:3.12-slim, node:20-alpine, nginx).
В логах должно появиться:

```
alfacredit-backend  | INFO:     Application startup complete.
alfacredit-frontend | ...
```

### 4. Открыть

- Приложение: **http://localhost:8080**
- API/Swagger: **http://localhost:8000/docs**

### 5. Остановить

```bash
docker compose down          # остановить
docker compose down -v       # остановить и удалить данные БД
```

Данные БД хранятся в папке `./data` на хосте (volume) и переживают перезапуск.

> Если порт 8000 или 8080 занят, поменяйте в `docker-compose.yml` левую часть портов,
> например `"18000:8000"` и `"18080:80"`, и открывайте http://localhost:18080
> (API при этом будет на http://localhost:18000).

## Способ B. Один процесс, без Node.js и Docker

Фронтенд уже собран в `frontend/dist`, FastAPI раздаёт его сам.

### Требования

- **Python 3.11 или новее** (проверено на 3.12 и 3.13)
- Проверка: `python3 --version` (Windows: `python --version`)

### Шаги

**1. Распаковать и зайти в папку**

```bash
unzip alfa-credit-cabinet-v1.0.0.zip
cd alfa-credit-cabinet
```

**2. Запустить скрипт**

Linux / macOS:

```bash
chmod +x start.sh
./start.sh
```

Windows (двойной клик по `start.bat` или из PowerShell):

```bat
start.bat
```

Скрипт сам создаст виртуальное окружение `backend/.venv`, установит зависимости из
`backend/requirements.txt`, наполнит БД демо-данными и поднимет сервер на порту 8000.

**3. Открыть http://localhost:8000**

**4. Остановить** — `Ctrl + C` в терминале.

### То же самое вручную (если скрипт не подходит)

Linux / macOS:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd ..
STATIC_DIR="$PWD/frontend/dist" uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

Windows PowerShell:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
cd ..
$env:STATIC_DIR="$PWD\frontend\dist"
uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

> Если PowerShell блокирует активацию окружения:
> `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

## Способ C. Режим разработки (hot-reload)

Нужны **Python 3.11+** и **Node.js 20+** (https://nodejs.org).

### Терминал 1 — backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Терминал 2 — frontend

```bash
cd frontend
npm install
npm run dev
```

Открыть **http://localhost:5173** — Vite проксирует запросы `/api` на `localhost:8000`.

### Сборка production-версии фронтенда

```bash
cd frontend
npm run build        # результат в frontend/dist
```

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATABASE_URL` | `sqlite:///./data/credit_cabinet.db` | Подключение к БД (можно PostgreSQL) |
| `JWT_SECRET` | dev-значение | Секрет подписи токенов — заменить в проде |
| `ACCESS_TOKEN_TTL_HOURS` | `12` | Время жизни токена |
| `DEMO_DELAY_SCALE` | `1.0` | Пауза между шагами конвейера. `0` — мгновенно |
| `OFFER_TTL_HOURS` | `168` | Срок действия предложения |
| `SEED_ON_START` | `true` | Наполнять БД демо-данными при старте |
| `CORS_ORIGINS` | `*` | Разрешённые origin |
| `STATIC_DIR` | — | Каталог собранного фронтенда (режим «один процесс») |

Пример для мгновенного конвейера:

```bash
DEMO_DELAY_SCALE=0 ./start.sh
```

## Если что-то не запускается

| Симптом | Причина и решение |
|---|---|
| `port is already allocated` / `Address already in use` | Порт занят. Освободите (`lsof -i :8000`, Windows: `netstat -ano \| findstr :8000`) или поменяйте порт |
| `python: command not found` | Python не установлен или не в PATH. Поставьте 3.11+ с python.org |
| `No module named app` | Запускаете не из папки `backend`. Используйте `--app-dir backend` или `cd backend` |
| `No module named fastapi` | Не активировано виртуальное окружение / не установлены зависимости: `pip install -r requirements.txt` |
| `npm: command not found` | Нужен Node.js 20+ (только для способа C и пересборки фронтенда) |
| Порт 8080 пустой после `docker compose up` | Подождите 30–60 с: фронтенд-образ собирается дольше бэкенда. Логи: `docker compose logs -f` |
| Страница открывается, но API отвечает 404 | Открыли не тот порт. UI: 8080 (Docker) / 8000 (способы B и C); API всегда `/api/...` |
| Забыл пароль/данные «сломались» | Удалите БД и перезапустите: `rm -rf data backend/data` (Docker: `docker compose down -v`) |
| Хочу изменить порт бэкенда | `uvicorn app.main:app --port 9000` + `VITE_API_TARGET=http://127.0.0.1:9000` для `npm run dev` |
| Docker на Windows: `docker-credential-desktop not found` | Перезапустите Docker Desktop, при необходимости перелогиньтесь в нём |
